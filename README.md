Weather Tracker


Weather Tracker is a web application that allows users to track the weather of different cities, including current conditions and 5-day forecasts. The app uses the OpenWeatherMap API to retrieve weather data and displays it to users in an intuitive interface.

Features

	•	Current Weather: View the current weather conditions of a specific city.
	•	5-Day Forecast: Get a 5-day forecast with weather updates every 3 hours.
	•	Search Functionality: Easily search for cities and get the weather data.

Installation

To set up the Weather Tracker app on your local machine, follow the instructions below:

1. Clone the repository

Clone the project repository from GitHub:
git clone https://github.com/yourusername/weather-tracker.git

2. Install dependencies

Navigate to the project folder and install the required dependencies for both the frontend and backend.

Frontend
cd client
npm install

backend
cd server
npm install

3. Configure environment variables

	•	Create a .env file in the root directory of the project.
	•	Add your OpenWeatherMap API key to the .env file:

Make sure to replace your_openweathermap_api_key with your actual OpenWeatherMap API key.

4. Run the app

You need to run both the frontend and backend servers.

Start the frontend

In the client directory:
npm run build

Start the backend

In the server directory:
npm run start

After both servers are running, open your browser and go to:
http://localhost:3001

Technologies Used

	•	Frontend: Vite, React
	•	Backend: Node.js, Express.js
	•	API: OpenWeatherMap API
	•	Styling: CSS
